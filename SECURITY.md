# Security Policy

## Supported Versions

Only actively maintained versions of HangBuddies receive security updates. Refer to our release notes for supported versions.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue. Instead, send a detailed report to [dan_jan1@icloud.com](mailto:dan_jan1@icloud.com) including steps to reproduce and any relevant logs or error messages.

## Response Process

- **Acknowledgment:** We will acknowledge receipt of your report within a period of time.
- **Investigation:** Our security team will assess the report and prioritize a fix based on severity.
- **Resolution:** We aim to resolve security issues promptly and will update you throughout the process.

## Responsible Disclosure

We appreciate responsible disclosure. Please give us reasonable time to address the vulnerability before discussing it publicly.

## Additional Information

For any questions regarding security practices, please contact our team at [dan_jan1@icloud.com](mailto:dan_jan1@icloud.com).
